{\bf Author Response: CHORD Hallucination Mitigation}
\end{center}

\textbf{Response focus.} We thank the reviewers for asking for mechanism, attribution, cost, and stronger-baseline evidence rather than only aggregate scores. We now make the response numeric and scoped: CHORD is a detector-assisted, base-MLLM training-free admission verifier for object-grounded hallucination/open-ended object mentions. Decoder-to-vision attention is used as an operational feature, not as a causal explanation.
