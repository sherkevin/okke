## Practical Takeaways For CHORD

- If we have only one page, do not attempt to reproduce the 5-page master. Convert it into one integrated evidence table plus short claim-boundary prose.
- Figures must earn their space. A figure is useful only if it removes a reviewer ambiguity faster than text.
- Tables should combine several concerns: mechanism, attribution, efficiency, and baseline fairness. A one-purpose table is too expensive.
- Reviewer-specific labels are useful, but full reviewer-by-reviewer paragraphs are not feasible in one page.
- Any optional Official Comment should be a short pointer or AC/SAC clarification, not a second full rebuttal.
